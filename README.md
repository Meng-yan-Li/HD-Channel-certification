# HD-Channel-certification

Mengyan Li, Yanning Jia, Fenzhuo Guo, Haifeng Dong, Sujuan Qin, Fei Gao, Semi-device-independent certification of high-dimensional quantum channels, [Phys. Rev. A 113, 062408](https://journals.aps.org/pra/abstract/10.1103/nvx7-1727).
